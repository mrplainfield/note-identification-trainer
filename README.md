This is a basic tool to train note identification and memorization on the guitar fretboard.
The tool displays a note and then plays back seven beats at a set tempo. 
The first beat should be used to identify the note.
The remaining beats are used to play the displayed note on each string of the guitar in the range between the first and the twelfth fret.
No open strings should be played.
Repeat the excercise until you can fluently do it with all natural notes mixed with all accidentals at 80 bpm.
Have fun practicing!
